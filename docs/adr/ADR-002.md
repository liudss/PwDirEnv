# ADR-002: Evaluate in a child PowerShell

Status: Accepted; reconciled with implementation on 2026-09-11.

## Context

Dot-sourcing in the host can change functions, aliases, prompts, and modules that cannot be reliably rolled back.

## Decision

Run embedded bootstrap and stdlib scripts in a noninteractive, profile-free child pwsh. Return results through a separate JSON file.

## Consequences

Only resulting environment changes are exported. Full evaluation incurs process startup. Timeout cleanup attempts to terminate the process tree; this does not restrict filesystem or network side effects.
