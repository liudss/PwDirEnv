# ADR-006: Apply environment changes only to Process scope

Status: Accepted; reconciled with implementation on 2026-09-11.

## Context

Project environments should have a shell-session lifetime without persistent system configuration changes.

## Decision

Host patches use Process scope only. Exec applies its patch to its own target child.

## Consequences

Shells keep separate restoration state, with nested-shell metadata in PWDIRENV_CONTEXT. Installation may configure PATH or a profile when requested; RC execution remains arbitrary user code, so this is not a restriction on what an approved script can do.
