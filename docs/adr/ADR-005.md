# ADR-005：Trust 基于内容 SHA-256

Status: Accepted

## Context

`.envrc.ps1` 是任意 PowerShell 代码（ADR-001）。若只按路径授权，攻击者只需在一次合法授权后向仓库推送修改过的脚本，用户 cd 进入时恶意代码即自动执行。目录级、mtime 级的信任都无法抵御"路径不变、内容被替换"的攻击。Windows 上也没有可依赖的、跨文件系统的稳定文件身份可作为替代。

## Decision

Trust record 基于文件内容的 SHA-256 哈希。`pwdir allow` 读取 RC bytes、计算 SHA-256，与 canonical 绝对路径一起写入 `%LOCALAPPDATA%\PwDirEnv\allow\`（atomic replace 写入）。任何一次执行前都重新校验内容哈希；内容变化一个 byte，状态立即回到 blocked，必须重新 `allow`。可选记录 Windows file ID 作为 rename 加固，但不能以 file ID 取代内容哈希。

## Consequences

- "仅 cd 进入陌生仓库"不会执行任何代码；未授权的 RC 绝不执行，包括为检测依赖而做的部分执行。
- 仓库更新替换脚本后自动失效，用户会感知到重新授权的提示。
- 代价是每次校验都要读取 RC 内容并计算哈希；单文件成本极低（远小于 spawn evaluator），不构成 hook 快速路径的瓶颈。
- 信任数据是用户级共享（多 shell 并发读安全），写入用 atomic replace 防止并发损坏。
