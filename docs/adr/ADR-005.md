# ADR-005: Authorize top-level content with SHA-256

Status: Accepted; reconciled with implementation on 2026-09-11.

## Context

Path-only authorization would silently permit a changed configuration to run.

## Decision

Store the top-level RC content hash with its lexical absolute path in a user-local record. Verify before evaluation and before accepting an export result or executing a target.

## Consequences

Top-level edits require renewed approval. Windows file IDs are not used; paths are not resolved through junctions. Pre/post checks do not eliminate replacement races. Sourced scripts are outside separate content authorization.
