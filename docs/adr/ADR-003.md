# ADR-003: Apply structured environment patches

Status: Accepted; reconciled with implementation on 2026-09-11.

## Context

Generated shell source would mix data and executable instructions and complicate restoration.

## Decision

Use schema-1 JSON with set/unset changes. The host applies Process environment entries directly and saves original existence/value per managed key.

## Consequences

No native output is evaluated as host code. Restoration discards manual changes to managed keys. Same-project reevaluation currently inherits applied values; it is not a clean baseline recomputation.
