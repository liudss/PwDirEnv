# ADR-008: Cache metadata and inherit session context

Status: Accepted; reconciled with implementation on 2026-09-11.

## Context

Unchanged projects should avoid evaluator startup, but cached environment values would persist secrets and cannot represent every shell baseline.

## Decision

Persist only fingerprint metadata. Keep restoration values in the host and inherit them through Base64 JSON in PWDIRENV_CONTEXT for nested shells. Force evaluation when a fresh host needs a full patch.

## Consequences

Every prompt still launches native export. Metadata checks can miss equal-size/equal-mtime changes; directory watches are not recursive. Inherited context contains values and is not encrypted. No latency guarantee is claimed.
