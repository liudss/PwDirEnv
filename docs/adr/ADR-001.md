# ADR-001: Use PowerShell configuration

Status: Accepted; reconciled with implementation on 2026-09-11.

## Context

Configuration needs conditionals, external tools, and native environment syntax.

## Decision

Use a valid `.envrc.ps1`, rather than a new configuration language. Bash `.envrc` files are not discovered.

## Consequences

Scripts are arbitrary code and require explicit top-level content approval. The process boundary is not a sandbox.
