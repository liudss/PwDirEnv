# ADR-004: Discover only the nearest RC

Status: Accepted; reconciled with implementation on 2026-09-11.

## Context

Implicit parent layering makes environment sources and overrides difficult to explain.

## Decision

Search upward for the nearest `.envrc.ps1`. Compose explicitly using `source_env` or `source_up`.

## Consequences

Source helpers track metadata and do not require separate authorization. Review their code with the top-level RC. Directory ancestry alone does not implicitly run parent scripts.
