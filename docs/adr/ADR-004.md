# ADR-004：只自动加载最近 RC

Status: Accepted

## Context

进入深层目录时，父目录链上可能存在多份 `.envrc.ps1`。若隐式叠加所有父级 RC，环境来源将难以推断：用户无法确定某个变量来自哪一层，多层之间的覆盖顺序、冲突行为也难以解释。direnv 的"最近配置"心智模型已被大量用户接受。

## Decision

从 cwd 向上搜索时，只选择**最近**（最深层）的一份 `.envrc.ps1` 自动加载，默认不隐式叠加多个父级 RC。需要父配置时，在 RC 内显式使用 `source_up`（搜索父目录中最近的 `.envrc.ps1`）或 `source_env '..\common\.envrc.ps1'` 组合。

## Consequences

- 环境来源可预测：当前生效的就是最近一份 RC，排障简单。
- 组合行为由用户显式声明，sourced 文件自动纳入 watch 依赖与 fingerprint，变更可触发重新 evaluate。
- 显式 `source_up` 的深度由项目作者掌控，避免隐式 layering 带来的意外。
