# ADR-007: Parse dotenv inside the evaluator

Status: Accepted; reconciled with implementation on 2026-09-11.

## Context

Dotenv helpers already run inside PowerShell and write that process environment. A native parser would add another process and serialization boundary.

## Decision

Implement the permissive dotenv parser in evaluator/stdlib.ps1. Do not retain an empty native parser placeholder.

## Consequences

There is no expansion or command substitution. Existing variables win unless Overload is set. Dotenv files need explicit watch registration. See ../configuration.md for exact syntax.
